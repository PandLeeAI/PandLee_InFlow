# 两部蒸馏怎样进入游戏

首次开局读取本页；具体世界、人物或节奏设计卡住时，再回读所链接的原始蒸馏。不要每回合加载所有报告。这里只迁移作用关系，不复制原作独有的副本顺序、身世谜底和整段场面链；玩家明确选原作世界时按 IF 分支主持。

## 原件、范围与本技能新增规则

原始蒸馏快照保存在 `source-distillations/`，逐文件原项目位置、字节数和 SHA-256 见 [来源清单](source-manifest.json)。快照原样保存，不打包两部小说全文。它们含原作谜底，属于主持资料，不主动展示给玩家。

- **《无限恐怖》**：优先 [六视角主笔总论](source-distillations/无限恐怖/六视角主笔总论.md)，结合 [全书因果与手法演进](source-distillations/无限恐怖/全书因果与手法演进.md)、[逐副本精读总览](source-distillations/无限恐怖/逐副本精读总览.md)。项目底本为用户提供的 TXT，已见终结段，不保证与官方逐字终版一致。研究是多人分工合读，不是每位研究者独立通读全书。总览记录30次真实世界访问，包含返乡、重访、训练和休假，不能按38个分集标题理解副本数。
- **《罪名不朽》**：使用 [研究总论](source-distillations/罪名不朽/研究总论.md)、[各副本的追读与情绪推进](source-distillations/罪名不朽/各副本的追读与情绪推进.md)及 [可迁移写法](source-distillations/罪名不朽/可迁移写法.md)。依据2026-11-17截至目录463章的连载快照；酆都、身份、亡友复活和完整宇宙史尚未闭合。不能冒称完本或官方终局。
- **两书对照**： [共同结论与写作运用](source-distillations/两书会师/共同结论与写作运用.md)区分亲入熟片、改命与重访，以及陌生世界求解、认识扩大；共同强调值得亲历的世界与有自己欲望的人。

原件内部相对链接、原文行号和旧路径保留作历史来源指针，部分目标不随包提供，**不是运行依赖**。离开原项目仍可用本页及技能规则完成游戏，不要因为档案链接缺目标就停在开局。外部评论不作为本游戏受欢迎的实证。

原件中的“必须、禁止、重构”等措辞保留当时的研究语境，属于观察或建议，不自动成为本游戏指令；主持以当前玩家约定和本技能的运行规则为准。

以下是“蒸馏所记原作观察 → 本技能的设计迁移”。观察和阅读效果判断来自项目研究；四选一、自由输入恢复、存档、分支管理及失败续玩等是为本次互动游戏新增的规则，不是原作者宣布的玩法。

## 1. 先让人想走进去，再让选择落地

《无限恐怖》总论“进入的诱惑”与前十章分析记录：熟悉电影的预期进入现场后，仍要经过身份、信任和执行条件；预知能招祸，也能救人。《罪名不朽》副本报告开局部分记录：局部目标先能理解，判断随后仍要靠行动完成，生还、分数和谢意才真正发生。

**游戏里**：入场先给可亲见的独特场面、可理解的目标和能执行的行动。选 A 以后现场必须响应，不连续几轮只解释设定；玩家对原作的知识可以起效，NPC 是否相信另据其身份和经历裁定。不熟悉原作也有眼前可用信息。

## 2. 改命通过人和条件，不通过轨道护栏

《无限恐怖》总论及两书对照写到，原片人物在新经历中可以作出新的选择，不能把当场行为倒推成早已安排。《罪名不朽》已见毁核复仇影响后来重返路线，私人所求改变了资源用途与择路条件。

**游戏里**：玩家干预 → 各方得知/失去什么 → 地方行动与资源变化 → 后续可能改变。保存分歧，不以“原著必须如此”撤销获救、死亡或结盟。也不保证玩家一句宣言就控制 NPC。

## 3. 世界异常长进生活，选项才有不同解法

罪名总论与迁移页记录，酆都的死亡失灵进入家庭等待、收容、劳动、军队与影像。无限总论与逐次访问记录，交易、雇工和工程长出当地的市场与生活，主角离开后当地仍有时间。

**游戏里**：从这一世界的条件推出不同人的利益与可行办法，A/B/C 才可能是调查、协商、战斗、经营、逃脱等真正不同路线。重访更新当地生活与政权，不原样复播。世界不仅给主角发奖，也有人不围着主角转。

## 4. 事实、证言、模型分开，发现可以逐层扩大

罪名研究区分“怀疑系统对鬼发题”与已经验证的事实、局部反馈与终极理论。两书对照又区分破局推理、文明发现和人物重新认识，它们不是同一种回报。

**游戏里**：保存已见事实、角色说法与玩家假说。给足行动所需信息，解谜前可获得决定性证据；重要秘密先固定，不因玩家猜中就更换。奇观、观看和理解本身也可满足，不把每次发现都换算成伤害加成。幻觉可以改判某种感知，但不无限清空整段投入。

## 5. 旧积累改变新打法，不每轮清零

两书都让既有能力在新世界起效，难题还来自身份、用途、目标、关系与认识。无限研究也区分购买能力、掌握程度和协作，并不把人物变强等同于变得无私。

**游戏里**：道具、能力、情报、技术与伙伴延续，熟练度与实际能力分开。玩家可以成长、复仇、控制、旅行或守护，不强制统一道德结局。很强就让其在适配冲突中很强，新挑战改变选择的性质，不凭空让所有敌人免疫旧本领。

## 6. 每场真结清，整个旅程仍可继续

罪名副本报告把超脱阶段的完成进度、救援、登船受保护、毁核和实际传送分别记录。无限终结研究也分开宿敌战结束、归返与彻底自由等尚未同等现场兑现的事项，批评晚追加条件不能遮蔽。

**游戏里**：公开目标、达成证据与离场规则明确，达标就兑现本场结果；找到救人的材料不等于已经见到人。支线与长期愿望可继续，但不能把奖励前再加一道门当作无限玩法。胜负之后可以休整、旅行、重访或开下一篇。

## 7. 奖励、相处与个人生活都是所得

两书对照区分得到复活用的书、真正找回一个人和约好明天钓鱼的不同满足；无限逐次访问中有交易、旅行和假日，罪名材料保留自利、报复与救友的坚持。

**游戏里**：把奖励给到可用、可享受的状态，让获救者之后能说话、办事、拒绝和改变关系。NPC 可以有独立贡献和日常，不只负责报线索或赞扬主角。宁静不必马上变成袭击前奏。

## 使用边界

这是基于现有蒸馏制作的互动主持方法，不等同于重新通读两部原作，更不证明原作者开篇就有研究者重建的同一份大纲。研究、技能格式检查、内部试玩和真实玩家反馈分别记录；不能从它们推出无限稳定、留存或商业成绩。
