# PandLee_InFlow

让 AI 担任无限流文字游戏主持人，让你作为主角走进不同世界，用选择改变剧情，尝试通关，并把所得带到下一程。

**作者信息：关注抖音 @熊黎 | PandLeeAI**

当前版本：**v1.0.1** · 技能调用标识：`pandlee-inflow`

## 这是什么

PandLee_InFlow 是供 AI Agent 加载的 Skill。宿主读取技能文件后，负责生成场景、扮演人物、回应行动、裁定结果和维护存档。

它以项目中《无限恐怖》和《罪名不朽》的蒸馏研究为参考，把世界探索、人物欲望、跨世界积累、认识扩大和阶段兑现，转化为互动玩法。

你可以进入原创世界，也可以指定已有小说、影视或其他作品的世界，按 IF 分支游玩。IF 表示从选定时间点开始，让后续随你的介入产生变化。

## 可以怎么玩

- **第一人称体验**：以“我”的亲历推进，观察环境、与角色交锋、寻找线索并作决定。
- **四选一交互**：每轮提供 A、B、C 三种行动，D 留给自由输入；直接描述行动也可以。
- **改变剧情**：救下谁、与谁合作、拿走什么、放弃什么，都可以影响后续路线和当地人的选择。
- **自选世界与角色方向**：可以指定目的地、时代、身份、能力、风格，或从默认入口开始。
- **跨世界积累**：保留实际获得的道具、本领、关系和世界改动，可以休整、重访或开启新篇。
- **有结果的副本**：胜利兑现所得；失败或死亡后，可以自行选择重试、另开分支、开启新局或结束。
- **可选图片**：宿主具备生图工具时，可辅助展示场景、氛围和道具；纯文字也能完成游玩。

## 安装

### Codex

1. 下载并解压技能包或本仓库。
2. 找到直接包含 `SKILL.md` 的文件夹，将该文件夹命名为 `pandlee-inflow`。
3. 把整个文件夹放入自己的 Codex 技能目录，保留其中的 `references/`、`assets/` 和 `agents/`。

默认安装位置示例（本项目实测 Windows 路径）：

| 系统 | 技能文件夹位置 |
| --- | --- |
| Windows | `%USERPROFILE%\.codex\skills\pandlee-inflow\` |
| macOS / Linux 的对应默认路径 | `~/.codex/skills/pandlee-inflow/` |

如果设置了自定义 `CODEX_HOME`，将文件夹放入该目录下的 `skills/`。

正确层级示例：

```text
skills/
└── pandlee-inflow/
    ├── README.md
    ├── SKILL.md
    ├── agents/
    │   └── openai.yaml
    ├── assets/
    │   └── session-template.json
    └── references/
        ├── source-methods.md
        ├── world-and-dungeon.md
        ├── input-and-ruling.md
        ├── state-and-save.md
        ├── source-manifest.json
        └── source-distillations/
```

让宿主重新发现技能，例如新开一个聊天；确认能找到 `pandlee-inflow` 后，输入下方的启动提示。若没有识别，先检查是否多套了一层文件夹，或只复制了 `SKILL.md` 而遗漏配套文件。

### 其他 Agent

将完整技能目录安装到该宿主支持的 Skill 位置，并让它读取 `SKILL.md` 及其中按需引用的文件。保存文件、生成图片等操作使用宿主自己的工具。

如果宿主只接受对话提示，可以提供技能入口及所需运行参考，让它按规则主持；这与原生 Skill 安装的发现方式不同。尚未对所有 Agent 宿主做兼容性实测。

## 快速开始

默认开局：

```text
使用 $pandlee-inflow 开始游戏。
```

自定义世界和身份：

```text
使用 $pandlee-inflow 开始。
我想进入一个原创的赛博朋克世界，以普通人身份开始。
风格偏推理和冒险，保持第一人称，每轮给我 A/B/C/D。
```

进入熟悉作品的分叉故事：

```text
使用 $pandlee-inflow。
我要去《西游记》的花果山，从猴王尚未出海求仙之前开始。
以普通旅人身份按 IF 游玩，让我的行动可以改变之后的故事。
```

如果宿主支持按名称自动识别，也可以直接说“用 PandLee_InFlow 开始游戏”。已安装但未被识别时，可以明确让宿主读取本地技能文件。

## 每轮怎么操作

AI 会先写出现场与上一行动的结果，再给下一组选择。每次只回一个字母就能继续：

| 输入 | 用法 |
| --- | --- |
| `A` / `B` / `C` | 执行最近一轮对应的行动 |
| `D：我想先和对方谈条件，暂时不交出道具。` | 提出菜单之外的做法 |
| `我先检查出口，再决定是否进入。` | 直接用自然语言描述行动，也能接续 |

只有 D、含糊的选择或桌外查询，会保留现场并给出下一步。自由行动根据当前能力、准备、环境和他人反应裁定；合理绕行可以成功，不存在的能力也不会因为一句宣言自动成立。

随时可以说“查看背包”“解释当前目标”“存档”“暂停”“继续”“换一个世界”或“结束游戏”。游戏等待你的输入，不会在你离开聊天后自行代玩。问规则和查状态不会偷偷消耗副本时间。

## 存档和续玩

宿主有文件工具时，默认在当前工作区建立：

```text
PandLee_InFlow/存档/<session_id>/
├── session.json
├── session.previous.json
└── checkpoints/
```

你也可以指定自己的存档目录。游戏存档与技能目录分开保存。

没有文件工具时，可以在当前聊天继续，并请求可复制的文本存档。跨聊天时要携带存档，不能依赖模型永久记住整段历史。

| 存档类型 | 内容与恢复范围 |
| --- | --- |
| 简易存档 | 只含已知状态与当前选项，无幕后剧透；可以摘要恢复，但未揭示的细节不保证完全一致 |
| 完整存档 | 包含人物状态、已发生事件、规则和未揭示设定，含剧透；适合完整迁移与续玩 |

在新聊天提供完整存档文件或可读取的路径，然后说：

```text
使用 $pandlee-inflow 读取这份完整存档继续。
先恢复当前情况和选项，不要替我自动行动。
```

## 模型和工具要求

技能未绑定特定模型。适合选择能遵循较长指令、处理多轮因果与人物关系的模型；本项目尚未做不同模型的对照测试。连续性仍需执行存档管理。

技能本身不需要额外安装 Python、Node.js、数据库或联网服务，也不需要单独配置 API Key；使用宿主已有的模型即可。宿主自己的账户、模型和工具按其配置运行。

文件保存和图片生成均取决于宿主能力。没有相应工具时继续文字玩法，不会把生成图片设为通关前提。

包内保留了7份原始蒸馏研究快照，位于 `references/source-distillations/`；逐文件来源和哈希见 [来源清单](references/source-manifest.json)，迁移方法见 [两书怎样进入游戏](references/source-methods.md)。这些资料包含原作剧透，直接游玩时无需手动阅读。

《罪名不朽》的参考范围截至2026-11-17目录第463章，酆都等线索尚未闭合，不作为完整终局研究。包内研究资料与小说全文有明确区分。历史研究里的部分回查链接指向原项目，不是游戏运行依赖。

“无限”通过可以继续开启的篇章、多世界和存档衔接实现。每个副本仍会有结果，实际体验也取决于模型与宿主；不承诺无限上下文或所有平台永久无故障。
